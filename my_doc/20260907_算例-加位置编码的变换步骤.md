# 算例:4 维位置编码——从 angles 生成到点积展开

> 展示 4 维嵌入下,位置指纹**如何由代码 `angles = pos / 10000 ** (idx / dim_model)` 逐步生成**,
> 以及后续"加进词向量 → 点积 → 展开四项"的完整变换链。只看变换,不求数值。
> 配套《位置编码:从加法到旋转》第二~四章。

---

## 设定

| token | 词向量 | 位置 |
|---|---|---|
| 甲 | a = (2, 4, 1, 3) | pos = 4 |
| 乙 | b = (3, 9, 2, 5) | pos = 7 |

嵌入维度 d_model = 4 → 列分 4 个:两对同频的 (sin, cos)。频率对的编号 i = 0, 1(对应偶数列 2i = 0, 2)。

代码(与项目 `model/position_encoding.py:14-19` 一致):

```python
pos = torch.arange(seq_len, dtype=torch.float).reshape(-1, 1)  # 行号(所有位置)
idx = torch.arange(0, dim_model, 2, dtype=torch.float)         # 偶数列下标 2i
angles = pos / 10000 ** (idx / dim_model)                      # ← 本算例主角
```

## 变换 ①:拆开 angles 的生成——先看两个输入张量的形状

我们只需要位置 4 和 7 两行,所以 seq_len = 2:

```
pos = [ 4 ]     形状 (2, 1):一列,每个位置一行
      [ 7 ]

idx = [ 0  2 ]  形状 (2,)   ← 注意是列号:偶数列下标 0 和 2(d_model=4 → arange(0,4,2))
```

**idx 为什么是 0 和 2**:代码只取偶数维。偶数列 2i 填 sin,紧邻的奇数列 2i+1 填 cos——所以每对同频占两列,4 列 → 2 个频率对。

## 变换 ②:10000 ** (idx / d_model)——每个频率对的"周期放大系数"

对每个 idx 代入:

```
idx / d_model →  0/4 = 0       2/4 = 0.5

10000 ** 0      = 1            ← 第 0 对频率:分母 1,相位 = pos × 1(最快)
10000 ** 0.5    = 100          ← 第 1 对频率:分母 100,相位 = pos × 1/100(慢 100 倍)
```

*规则:这是论文公式 10000^(2i/d_model) 的逐列计算,结果称为"系数行"。*

## 变换 ③:pos 除以系数——逐格相除,得到 angles 矩阵

*规则:广播——pos 是 (2,1) 的列,系数是 (2,) 的"行",逐元素相除后得到 (2,2):每一行 = 一个位置对两个频率的相位。*

```
angles = pos / [ 1  100 ]      (把系数行展开写)

        第0对      第1对
位置4  [ 4/1     4/100 ]   = [ 4       0.04   ]
位置7  [ 7/1     7/100 ]   = [ 7       0.07   ]
        ↑ pos=4 对两个频率     ↑ 相位 = pos / 10000^(2i/d_model),论文公式原样
```

**angles 的每个格子就是论文公式括号里的值**:第 (pos, i) 格 = pos / 10000^(2i/d_model)。代码里没有显式的双层循环,一次广播除法就生成了整个相位矩阵。

## 变换 ④:由 angles 填出 PE 矩阵

*规则:偶数列(0, 2)填 sin(angles),奇数列(1, 3)填 cos(angles)——每对同频的 sin/cos 共用同一列相位。*

```
PE 矩阵(行=位置,列=维度):

         列0 sin(·)   列1 cos(·)    列2 sin(·)   列3 cos(·)
位置4   sin(4)      cos(4)       sin(0.04)    cos(0.04)     ← 这一行 = PE(4)
位置7   sin(7)      cos(7)       sin(0.07)    cos(0.07)     ← 这一行 = PE(7)
        ↑ 第0对:θ=1    ↑                ↑ 第1对:θ=1/100
```

写成向量(与代码 `pe = PE(pos)` 对应):

$$
\text{PE}(4) = \big( \sin(4),\ \cos(4),\ \sin(0.04),\ \cos(0.04) \big)
$$

$$
\text{PE}(7) = \big( \sin(7),\ \cos(7),\ \sin(0.07),\ \cos(0.07) \big)
$$

*每个分量的来源都可回查:第 1、2 位来自 angles 第 0 列(频率快),第 3、4 位来自 angles 第 1 列(频率慢 100 倍)。*

## 变换 ⑤:词向量 + 指纹 = 实际输入(逐维相加)

$$
x_a = a + \text{PE}(4) = (2,\ 4,\ 1,\ 3) + \big( \sin(4),\ \cos(4),\ \sin(0.04),\ \cos(0.04) \big)
$$

$$
x_b = b + \text{PE}(7) = (3,\ 9,\ 2,\ 5) + \big( \sin(7),\ \cos(7),\ \sin(0.07),\ \cos(0.07) \big)
$$

*规则:向量加法 = 逐维相加。*

## 变换 ⑥:点积 + 分配律 → 四项

$$
x_a \cdot x_b = \big( a + \text{PE}(4) \big) \cdot \big( b + \text{PE}(7) \big)
$$

*规则:分配律(点积对加法线性),一个点积拆四个:*

$$
= a \cdot b + a \cdot \text{PE}(7) + \text{PE}(4) \cdot b + \text{PE}(4) \cdot \text{PE}(7)
$$

每项都按点积定义展开成**四维分量的和**(以④为例,其余同理):

$$
\text{PE}(4) \cdot \text{PE}(7)
= \sin(4)\sin(7) + \cos(4)\cos(7) + \sin(0.04)\sin(0.07) + \cos(0.04)\cos(0.07)
$$

## 变换 ⑦:④ 收缩——每对同频各自用和差化积,只剩位置差

*规则:对第 0 对(sin(4),cos(4))·(sin(7),cos(7)) 用 cos α cos β + sin α sin β = cos(α−β);第 1 对同理。两个频率对互不混合,各自收缩:*

$$
\begin{aligned}
④ &= \big[ \sin(4)\sin(7) + \cos(4)\cos(7) \big] + \big[ \sin(0.04)\sin(0.07) + \cos(0.04)\cos(0.07) \big] \\
  &= \cos(7 - 4) + \cos(0.07 - 0.04) \\
  &= \cos(1 \cdot 3) + \cos\big(\tfrac{1}{100} \cdot 3\big)
\end{aligned}
$$

*注意第 2 个括号里 0.07 − 0.04 = 0.03:它其实是 θ₂·(7−4)(θ₂ = 1/100)。写成通用形式:*

$$
④ = \cos\big(\theta_1 \cdot (7-4)\big) + \cos\big(\theta_2 \cdot (7-4)\big) = \sum_{i} \cos\big(\theta_i \cdot \text{位置差}\big)
$$

**绝对位置 4、7 全部消掉,只剩位置差 3;d=4 时④是 2 个 cos 的和(每对频率贡献一个)。**

## 全链一览

```
a = (2,4,1,3), b = (3,9,2,5), pos 4 / 7
   │
   ▼ ①-③   angles = pos / 10000**(idx/d_model),广播生成 (2,2) 相位矩阵
            位置4 → (4, 0.04)    位置7 → (7, 0.07)
   │
   ▼ ④   偶列 sin、奇列 cos → 填出 PE 矩阵,取行得 PE(4)、PE(7)(4 维向量)
   │
   ▼ ⑤   逐维相加: x_a = a + PE(4), x_b = b + PE(7)
   │
   ▼ ⑥   点积定义 → 分配律展开: ①词义 + ②③混合 + ④位置
   │
   ▼ ⑦   ④ 按频率对和差化积 → cos(θ₁·3) + cos(θ₂·3) = Σᵢ cos(θᵢ·位置差)
```

## 这套变换说明了什么

1. **angles 一步广播 = 论文公式的逐格代入**:代码的 `pos`(行)与 `idx`(列)两个向量相除,天然生成"位置 × 频率对"的相位矩阵,不用写双层循环
2. **PE 矩阵的每个格子都能回查到 angles 的某一格**:偶列填 sin、奇列填 cos,同频配对
3. **④ 的长度 = 频率对数**:维度越大,④ 的 cos 项越多(256 维 = 128 个 cos 之和),每项都是一把"不同精度的距离尺子"(见主文档第五章)
