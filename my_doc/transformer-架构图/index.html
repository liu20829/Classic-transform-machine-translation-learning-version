总览：从 src 到输出概率

这份结构图怎么读

src 进编码器，编码器输出再喂给解码器的交叉注意力；tgt 自己走一遍解码器。形状全程保持【batch, len, d_model】，靠残差相加约束。

编码器里一个（普通自注意力），解码器里两个（带因果掩码的自注意力 + 交叉注意力）。三处用的是同一个类，只有喂进去的 Q K V 和 mask 不同。

节点里的形状用【】全角括号（Mermaid 语法占用半角括号）。精确写法见右侧各卡片里的表格。

1) 本实现把缩放写成 sqrt_d_model，论文是 sqrt_d_k；2) 图上最后的 Softmax 在代码里是省略的，交给损失函数做。

输入与两个掩码

model/transformer.py:27-46 
# 源端掩码：只遮 padding
def make_input_mask(self, input):
    input_mask = (input != self.padding_index).unsqueeze(1).unsqueeze(2)
    return input_mask

# 目标端掩码：padding 与 下三角 的与
def make_target_mask(self, target):
    target_pad_mask = (target != self.padding_index).unsqueeze(1).unsqueeze(2)
    target_tril_mask = torch.tril(torch.ones((target.shape[1], target.shape[1]),
                                             device=self.device)).bool()
    target_mask = target_pad_mask & target_tril_mask
    return target_mask

def forward(self, src, tgt):
    src_mask = self.make_input_mask(src)
    encoded_input = self.encoder(src, src_mask)        # 编码器只吃 padding mask
    target_mask = self.make_target_mask(tgt)
    output, attention = self.decoder(tgt, encoded_input, target_mask, src_mask)
    return output, attention

编码器层：两个子层

model/encoder.py:39-47 
def forward(self, src, mask):
    # 自注意力：Q K V 传的都是同一个 src
    attention, _ = self.attention(src, src, src, mask)
    attention_norm = self.norm1(src + self.dropout(attention))

    forward = self.feed_forward(attention_norm)
    output = self.norm2(attention_norm + self.dropout(forward))
    return output

解码器层：三种注意力的三次调用

model/decoder.py:45-59 
def forward(self, target, encoded_input, target_mask, input_mask):
    # 1. 带因果掩码的自注意力：Q K V 都来自 target
    attention_1, _ = self.attention1(target, target, target, target_mask)
    attention_1_norm = self.norm1(target + self.dropout(attention_1))

    # 2. 交叉注意力：Q 来自解码器，K V 来自编码器
    attention_2, attention = self.attention2(attention_1_norm, encoded_input,
                                             encoded_input, input_mask)
    attention_2_norm = self.norm2(attention_1_norm + self.dropout(attention_2))

    # 3. 前馈网络
    forward = self.feed_forward(attention_2_norm)
    output = self.norm3(attention_2_norm + self.dropout(forward))
    return output, attention

解码器层内部：三种注意力对照

三种注意力的区别只有两处：Q K V 来自谁、mask 是什么

Q K V 全部来自 src；mask 是 src_mask，只遮 padding。代码：self.attention(src, src, src, mask)

Q K V 全部来自 target；mask 是 target_mask，等于 padding 与 下三角 的与，既遮填充又遮未来。代码：self.attention1(target, target, target, target_mask)

Q 来自解码器状态，K V 来自编码器输出；mask 是 input_mask，只遮 padding，不遮未来。代码：self.attention2(attention_1_norm, encoded_input, encoded_input, input_mask)

这个类的接口是 Q K V mask 到 output，它不关心 Q 从哪来。角色由输入来源决定，不由算子内部决定。

缩放点积注意力内部：形状流转

形状流水线（以 batch=10、len=50、d_model=128、heads=8 为例）

【10, 50, 128】经 view 与 permute 拆头成【10, 8, 50, 16】。拆的是特征维：第 h 个头拿坐标 h 乘 16 到 h 乘 16 加 15。

【10, 8, 50, 16】乘【10, 8, 16, 50】得到【10, 8, 50, 50】。共享维是 D_k=16，被消掉；留下两个 token 维。

被遮位置填 -1e10，softmax 后约等于 0。形状不变，每行 50 个权重和为 1。

【10, 8, 50, 50】乘【10, 8, 50, 16】得到【10, 8, 50, 16】。这次共享维是 len_k=50，被消掉。

permute 加 contiguous 加 view，把 8 个 16 维拼成 128 维，回到【10, 50, 128】，再做输出投影 W_O。

第一次沿特征维求和，算的是谁跟谁像；第二次沿位置维求和，算的是把谁的 value 按比例取过来。
